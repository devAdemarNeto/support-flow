# SupportFlow

Sistema de gerenciamento e suporte a fluxos de atendimento.

## Stack Planejada

- **Linguagem**: PHP 8+ (Programação Orientada a Objetos)
- **Gerenciador de Dependências / Autoload**: Composer & PSR-4
- **Banco de Dados (futuro)**: PostgreSQL & PDO
- **Frontend**: HTML5, CSS3 e JavaScript puro
- **Arquitetura**: MVC com Services e Repositories

## Status

Projeto em desenvolvimento.
